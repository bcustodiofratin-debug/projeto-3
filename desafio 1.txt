# Lista para armazenar os votos
votos = []

# Entrada de dados
while True:
    voto = input("Digite o nome do candidato (Ana, Bruno ou Carlos) ou 'fim' para encerrar: ").strip().lower()
    
    if voto == "fim":
        break
    
    if voto in ["ana", "bruno", "carlos"]:
        votos.append(voto)
    else:
        print("Candidato inválido! Tente novamente.")

# Contagem dos votos
votos_ana = votos.count("ana")
votos_bruno = votos.count("bruno")
votos_carlos = votos.count("carlos")

# Exibição dos resultados
print("\nResultado da eleição:")
print(f"Ana: {votos_ana} votos")
print(f"Bruno: {votos_bruno} votos")
print(f"Carlos: {votos_carlos} votos")

# Determinar o vencedor
maior = max(votos_ana, votos_bruno, votos_carlos)

# Verificar empate
vencedores = []
if votos_ana == maior:
    vencedores.append("Ana")
if votos_bruno == maior:
    vencedores.append("Bruno")
if votos_carlos == maior:
    vencedores.append("Carlos")

if len(vencedores) == 1:
    print(f"Vencedor: {vencedores[0]}")
else:
    print("Houve empate entre:", ", ".join(vencedores))

# Editor simples com desfazer (usando pilha)

pilha = []

while True:
    print("\n--- Editor de Texto ---")
    print("1 - Digitar palavra")
    print("2 - Desfazer (pop)")
    print("3 - Mostrar texto atual")
    print("0 - Sair")

    opcao = input("Escolha uma opção: ")

    if opcao == "1":
        palavra = input("Digite uma palavra: ")
        pilha.append(palavra)
        print("Palavra adicionada!")
    
    elif opcao == "2":
        if len(pilha) > 0:
            removida = pilha.pop()
            print(f"Desfeito! Palavra removida: {removida}")
        else:
            print("Erro: nada para desfazer (pilha vazia).")
    
    elif opcao == "3":
        if len(pilha) > 0:
            texto = " ".join(pilha)
            print("Texto atual:", texto)
        else:
            print("Texto vazio.")
    
    elif opcao == "0":
        print("Saindo...")
        break
    
    else:
        print("Opção inválida!")

    # Exibe automaticamente após cada operação
    if len(pilha) > 0:
        print("Texto atualizado:", " ".join(pilha))
    else:
        print("Texto atualizado: (vazio)")

# Sistema de atendimento de alunos (Fila - FIFO)

fila = []

while True:
    print("\n--- Secretaria de Atendimento ---")
    print("1 - Adicionar aluno na fila")
    print("2 - Atender próximo aluno")
    print("3 - Exibir fila atual")
    print("0 - Sair")

    opcao = input("Escolha uma opção: ")

    if opcao == "1":
        nome = input("Digite o nome do aluno: ")
        fila.append(nome)
        print(f"{nome} entrou na fila!")

    elif opcao == "2":
        if len(fila) > 0:
            atendido = fila.pop(0)  # FIFO
            print(f"Atendendo: {atendido}")
        else:
            print("Erro: fila vazia, ninguém para atender.")

    elif opcao == "3":
        if len(fila) > 0:
            print("Fila atual:", " -> ".join(fila))
        else:
            print("Fila vazia.")

    elif opcao == "0":
        print("Encerrando sistema...")
        break

    else:
        print("Opção inválida!")

    # Exibe automaticamente após cada operação
    if len(fila) > 0:
        print("Fila atualizada:", " -> ".join(fila))
    else:
        print("Fila atualizada: (vazia)")

# Sistema de Registro de Votos (Python)

## 📌 Descrição
Este projeto simula um sistema simples de votação para escolha de representantes de classe. O usuário pode inserir votos para três candidatos (Ana, Bruno e Carlos), e o sistema contabiliza os resultados.

## ⚙️ Funcionalidades

- Entrada contínua de votos até o usuário digitar **"fim"**
- Armazenamento dos votos em uma lista
- Validação de candidatos (evita nomes inválidos)
- Contagem de votos usando `count()`
- Identificação automática do vencedor
- Tratamento de empate entre dois ou três candidatos

## 🧠 Lógica Principal

### ✔️ Armazenamento
Os votos são guardados em uma lista:
python
votos = []

### ✔️ Contagem

Utiliza o método `count()`:
python
votos.count("Ana")

* Primeiro encontra o maior número de votos:
python
max_votos = max(votos_ana, votos_bruno, votos_carlos)

python
if votos_ana == max_votos:

### ✔️ Tratamento de empate

* Se mais de um candidato tiver o maior número de votos:
python
if len(vencedores) > 1:
    print("Empate entre:", vencedores)

# 🧠 Simulação de Pilha (LIFO) em Python

## 📌 Descrição

Este projeto simula o comportamento de uma **pilha (stack)** utilizando Python.

A estrutura segue o princípio **LIFO (Last In, First Out)**, ou seja:

> A última palavra adicionada será a primeira a ser removida.

## ⚙️ Funcionalidades

* ➕ Adicionar palavras à pilha (`append`)
* ↩️ Desfazer a última palavra (`pop`)
* 👀 Exibir o texto atual
* ⚠️ Tratamento de erro ao tentar remover com a pilha vazia

## 🧪 Como funciona

O programa utiliza uma lista (`list`) para representar a pilha:

* `append()` → adiciona palavra no topo
* `pop()` → remove a última palavra inserida

## ▶️ Execução

1. Execute o arquivo Python:
bash
python nome_do_arquivo.py

2. Use o menu interativo:

* `1` → Adicionar palavra
* `2` → Desfazer última palavra
* `3` → Exibir texto
* `4` → Sair

## 💡 Exemplo de uso

Entrada:

Adicionar: Olá
Adicionar: Mundo

Saída:

Texto atual: Olá Mundo

Desfazendo:

Removido: Mundo
Texto atual: Olá

## 📚 Conceito aplicado

* Estrutura de dados: **Pilha (Stack)**
* Princípio: **LIFO (Last In, First Out)**

## 🚀 Possíveis melhorias

# 📚 Sistema de Fila de Atendimento (FIFO)

## 📌 Descrição

Este projeto simula um sistema de atendimento de alunos em uma secretaria, seguindo o modelo **FIFO (First In, First Out)**, ou seja, o primeiro aluno a entrar na fila é o primeiro a ser atendido.

## ⚙️ Funcionalidades

* ➕ **Adicionar aluno à fila**

  * Utiliza `append()` para inserir no final da lista.

* 🎯 **Atender aluno**

  * Utiliza `pop(0)` para remover o primeiro da fila.

* 📋 **Exibir fila atual**

  * Mostra todos os alunos na ordem de atendimento.

* ⚠️ **Tratamento de fila vazia**

  * Evita erros ao tentar atender sem alunos na fila.

## 🧠 Conceito Utilizado

### FIFO (First In, First Out)

Estrutura onde:

* O primeiro elemento inserido é o primeiro a sair.
* Muito utilizado em filas reais (banco, mercado, atendimento).

## ▶️ Como Executar

1. Certifique-se de ter o Python instalado.
2. Salve o código em um arquivo `.py` (ex: `fila.py`).
3. Execute no terminal:
bash
python fila.py

Digite o nome do aluno: João

3 - Exibir fila
